## 🚀 What You Will Learn in Day 05

Day 05 focuses on **ROS2 Actions** and provides hands-on experience with **asynchronous long-running tasks with feedback**. By the end of this session, you will be able to:

### ✅ Understand ROS2 Actions (Manual 1)  
- Difference between **Topics, Services, and Actions**  
- Concept of **asynchronous request with feedback and result**  
- Structure of a `.action` file (goal, feedback, result)  
- How to create a ROS2 package for actions  
- Build and prepare the package for Python action nodes  

### ✅ Create an Action Server Node (Manual 2)  
- Write a Python ROS2 action server node  
- Use `ActionServer` to define action type and execute callback  
- Handle goals, send periodic feedback, and return results  
- Log received goals and progress in the terminal  

### ✅ Create an Action Client Node (Manual 2)  
- Write a Python ROS2 action client node  
- Use `ActionClient` to connect to server  
- Send goals, receive real-time feedback, and get the result  
- Print server feedback and final result in the terminal  

### ✅ Run and Test Actions  
- Start the action server node with `ros2 run`  
- Start the action client node with `ros2 run`  
- Observe goal feedback in real-time  
- Confirm the final result is returned from the server  

### ✅ Concepts Covered  
- Goal, feedback, and result structure in `.action` files  
- Asynchronous communication and long-running tasks  
- How actions differ from topics and services  
- Step-by-step beginner-friendly code execution
