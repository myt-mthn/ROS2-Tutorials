## 🚀 What You Will Learn in Day 03

Day 03 focuses on **inspecting ROS2 nodes, topics, and services**, and **visualizing your system** using `rqt` and `rqt_graph`.  
By the end of this session, you will be able to:

### ✅ Inspect Running ROS2 Nodes  
- List all active nodes using `ros2 node list`  
- Check subscriptions, publications, and services of a node using `ros2 node info`  
- Verify if nodes from Day 1 & 2 are running, and launch them if not  

### ✅ Inspect Topics and Message Flow  
- List all topics using `ros2 topic list`  
- Get detailed information on a topic with `ros2 topic info`  
- Understand message types and structure using `ros2 interface show`  
- Troubleshoot missing publishers or subscribers  

### ✅ Inspect and Call Services  
- List all services using `ros2 service list`  
- Check the type of a service using `ros2 service type`  
- Call a service to test functionality using `ros2 service call`  

### ✅ Use rqt for Visualization  
- Launch `rqt` to view nodes and topics graphically  
- Explore useful plugins: `rqt_graph`, `rqt_plot`, `rqt_topic`, `rqt_logger_level`, `rqt_publisher`  
- Refresh rqt if nodes are launched after opening  

### ✅ Use rqt_graph for Live Computation Graph  
- Visualize all nodes, topics, and data flow  
- Identify missing connections or unexpected nodes  
- Debug your ROS2 system visually  
- Confirm correct communication in a real robot example (IMU → Controller → Motors)
