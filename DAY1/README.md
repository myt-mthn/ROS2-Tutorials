# ROS2 Tutorials — Day 1

Welcome to **Day 1** of the ROS2 Tutorials repository by *myt-mthn*.  
This tutorial introduces ROS2 basics, creating a workspace, creating a Python package, and writing your first Python node.

---

## Prerequisites

- Ubuntu 20.04 or 22.04  
- ROS2 Humble (or compatible) installed  
- Basic knowledge of Linux commands  

---

## What You Will Learn

- ROS2 fundamentals: nodes, packages, workspaces  
- Creating a ROS2 Python package  
- Writing a Python node manually  
- Building and running nodes with `colcon`
