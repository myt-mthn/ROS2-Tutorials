## 🚀 What You Will Learn in Day 02

Day 02 focuses on getting hands-on with ROS2 communication.  
By the end of this session, you will be able to:

### ✅ Create a ROS2 Package  
- Understand the structure of a ROS2 Python package  
- Learn the purpose of `setup.py`, `package.xml`, and directory layout  

### ✅ Write Your First Publisher Node  
- Publish messages on a topic  
- Control publish frequency using timers  
- Use standard message types  

### ✅ Write Your First Subscriber Node  
- Subscribe and receive data from a topic  
- Handle callbacks  
- Print incoming messages  

### ✅ Run and Test Nodes  
- Use `ros2 run` to execute nodes  
- Echo a topic with `ros2 topic echo`  
- List active topics with `ros2 topic list`  

### ✅ Understand Node Discovery and Communication  
- How publishers and subscribers find each other  
- Basic QoS idea (no deep theory)
